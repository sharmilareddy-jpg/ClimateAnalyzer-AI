7-DAY PROTOTYPE ESTIMATES

Climate-risk indicators

Prototype only

These estimates use the selected location's 7-day forecast and your soil-moisture entry. They are not validated crop predictions.

Show factor tables and scoring rules

Crop parameters (p / Kc mid): Rice 0.20 / 1.20; Wheat 0.55 / 1.15; Maize 0.55 / 1.20; Cotton 0.65 / 1.175 (midpoint of FAO's 1.15–1.20 range); Groundnut 0.50 / 1.15; Sugarcane 0.65 / 1.25; Tomato 0.40 / 1.15. FAO-56 p is allowable depletion before stress (ETc about 5 mm/day); its rice value is reported relative to saturation and is used here only as a prototype threshold. Kc mid is the crop water-use coefficient. The heat proxy uses Kc mid / 1.15; it scales heat-driven water demand and is not a crop heat-injury threshold.

Soil parameters (relative retention ratio / p adjustment / drainage factor): Sandy 0.60 / +0.10 / 0.90; Clay 0.80 / −0.10 / 0.30; Loamy 1.00 / 0 / 0.70; Silty 1.13 / −0.05 / 0.50; Black soil 0.80 / −0.10 / 0.25; Red soil 0.60 / +0.05 / 0.80. Retention ratios are normalized representative available-water-capacity proxies (reference 150 mm/m; FAO-56 Example 36 gives 90 mm/m for loamy sand, 120 for silty clay and 170 for silt). p adjustments use FAO's coarse +5–10% / fine −5–10% guidance. Drainage factor is a normalized 0–1 class estimate (0 = very slow, 1 = rapid), not measured hydraulic conductivity; Black and Red soil use the proxies described above.

Drought: effective depletion = clamp((1 − moisture% / 100) / retention ratio, 0, 1); adjusted p = clamp(crop p + soil p adjustment, 0.10, 0.80); moisture stress = clamp((effective depletion − adjusted p) / (1 − adjusted p) × 100, 0, 100). Rain deficit = clamp((20 − actual 7-day rain mm) / 20 × 100, 0, 100). Heat stress = clamp((actual mean daily forecast high °C − 30) / 10 × 100, 0, 100). Drought score = 40% moisture stress + 30% (rain deficit × Kc mid / 1.15) + 30% (heat stress × Kc mid / 1.15); component scores are capped at 100.

Heavy rainfall: intensity = clamp((actual maximum daily forecast rain mm − 20) / 30 × 100, 0, 100), so 20 mm/day starts the scale and 50 mm/day reaches 100. Saturation = clamp((entered moisture% − 60) / 40 × 100, 0, 100). Drainage risk = (1 − drainage factor) × intensity. Score = 70% intensity + 15% saturation + 15% drainage risk. Moisture is a user-entered normalized estimate, not an API or sensor measurement. See FAO-56 water-stress guidance and FAO-56 crop coefficients.
